# Artist Management System - Overview Component

## Overview

The Overview component provides a comprehensive dashboard for artist managers to monitor key metrics and recent bookings. It includes real-time data updates, interactive elements, and a clean, modern UI design.

## Features

### Overview Cards (Flashcards)
- **Total Revenue**: Dynamically calculates and displays the sum of all paid bookings from artist booking prices
- **Total Artists**: Shows count of registered artists in the system
- **Pending Approvals**: Number of artist applications awaiting approval from the `/applications` endpoint
- **Rejected Approvals**: Number of rejected artist applications from the `/applications` endpoint

### Artist Bookings Table
- Displays all bookings for artists in the system
- Columns: Customer Name, Artist Booked, Event Date, Event Type, Payment Status, Venue
- Real-time updates when new bookings are made
- Status badges with color coding (pending, paid, failed)

### Revenue by Artist Chart
- Interactive bar chart showing revenue generated by each artist
- X-axis displays artist names, Y-axis shows revenue amounts
- Tooltips display exact revenue values on hover
- Responsive design that adapts to different screen sizes
- Automatically updates when new bookings are paid
- Sorted by revenue (highest to lowest)

### Real-time Updates
- Automatic data refresh every 30 seconds
- Manual refresh button for immediate updates
- Error handling with retry functionality
- Loading states for better user experience

### PDF Report Generation
- Generate comprehensive PDF reports with current system statistics
- Includes overview metrics, revenue breakdown, and recent bookings
- Professional formatting with company branding and timestamps
- Automatic download with descriptive filename

## API Endpoints Used

### Backend Routes
- `GET /bookings` - Fetch all artist bookings
- `GET /artists` - Fetch all artists and their approval statuses
- `GET /artists/applications` - Fetch artist applications with pending, approved, and rejected counts

## Usage

1. **Install required libraries**:
   ```bash
   npm install recharts jspdf jspdf-autotable
   ```

2. **Import the component**:
   ```jsx
   import Overview from './Components/Manuth/Overview/Overview';
   ```

3. **Add to your routes** (already configured):
   ```jsx
   <Route path="/overview" element={<Overview />} />
   ```

4. **Ensure backend is running** on port 5000

5. **Access via navigation**: The Overview page is accessible through the Artist Manager Dashboard navigation

## Troubleshooting

### Common Issues

1. **No data displayed**: Check if backend is running and API endpoints are accessible
2. **Revenue not calculating**: Ensure artist profiles have `bookingPrice` field populated
3. **Navigation not working**: Verify that all navigation components are properly imported
4. **Chart not rendering**: Ensure Recharts library is installed (`npm install recharts`)
5. **Chart data empty**: Check if there are paid bookings with valid artist data and booking prices
6. **PDF generation fails**: Ensure jsPDF and jsPDF-AutoTable are installed (`npm install jspdf jspdf-autotable`). The import order matters - import jsPDF first, then autoTable.

### API Requirements

- Backend must be running on `http://localhost:5000`
- Artist bookings must include populated artist data with `bookingPrice`
- Artist applications endpoint (`/artists/applications`) must return pending, approved, and rejected arrays
